# is

> [!Note]
> Original Intention:
>
> The "is" function you need is definitely needed by someone in the world.

This "is" project is aimed to build a useful determine tool by "is". Welcome for everyone to create PR for any "is" statement.

| Target | Releated Functions | Author |
| - | - | - |

## Contribution Guide

1. Please find which type you want to contribute, and go to the corresponding go file.
2. Create a new file for new "is" statement is also welcome.
3. Please make sure you have the **STRICT** unit test for new "is" function.
4. Update the "is" table at this README and leave your account at author column.
5. Create a PR directly!
